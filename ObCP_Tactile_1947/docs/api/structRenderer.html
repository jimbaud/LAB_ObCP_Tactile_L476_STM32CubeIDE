Description détaillée

Machine d’état du rendu par bandes.

La liste batch est figée pour le lot courant. Les nouvelles invalidations restent dans la liste pending de l’application. Le tampon est exclusivement possédé par le CPU ou par le transport.

Définition à la ligne 244 du fichier obcp_gfx.h.
