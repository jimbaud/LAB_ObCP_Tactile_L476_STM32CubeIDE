Description détaillée

Filtrage du contact, de SW1 et de l’inclinaison.

Les pilotes livrent des états physiques. Ce module construit les événements DOWN, MOVE et UP, rejette les oscillations et exprime les commandes de jeu dans le repère de l’écran. Les temps sont en millisecondes et les accélérations en g.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.
