Description détaillée

Pilote de l'accéléromètre LIS3DH (ou LIS3DSH) sur SPI3 (voir accelerometer.h).

Dialogue SPI avec le capteur : la carte (maître) met CS à 0, envoie un premier octet qui dit quoi faire, puis échange les données ; CS repasse à 1 à la fin. En SPI, chaque octet envoyé fait revenir un octet : pour lire, on envoie des octets sans importance (0) pendant que le capteur renvoie ses registres.

Premier octet (LIS3DH, datasheet § 6.2.1) : bit 7 RW : 1 = lecture, 0 = écriture bit 6 MS : 1 = l'adresse avance d'un cran après chaque octet (pour lire plusieurs registres qui se suivent) bits 5..0 adresse du premier registre Le LIS3DSH n'a pas de bit MS (son adresse fait 7 bits) : l'avance automatique y est réglée une fois pour toutes (bit ADD_INC de CTRL_REG6).

La version 2024 utilisait les sensibilités du LIS3DSH (0,06 mg par pas) avec un LIS3DH (0,0625 mg par pas en mode haute résolution) : ses accélérations étaient 4 % trop faibles. Elle lisait aussi les trois axes en trois échanges séparés (axes de mesures différentes) et copiait la structure de gestion du SPI (deux copies pour un seul périphérique).
