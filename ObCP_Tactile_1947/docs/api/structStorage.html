Description détaillée

Interface physique de stockage injectable dans les tests.

Toutes les adresses sont des offsets dans la réserve du linker. Les callbacks synchrones sont appelés dans la boucle principale. Le port STM32 et la flash simulée partagent ce contrat.

◆ erase

bool(*) Storage::erase(void *context, uint32_t offset, uint32_t count)

Effacer count octets à partir de offset. Offset et count doivent représenter des pages complètes de 2 Kio. true confirme l'effacement.
