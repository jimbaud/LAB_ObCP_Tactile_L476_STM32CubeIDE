Description détaillée

Synthèse numérique et séquenceur musical sans accès matériel.

Les échantillons sont des valeurs de comparaison CCR3 sur 10 bits, centrées autour de

  1. Le transport DMA consomme ces valeurs à 15 625 échantillons par seconde. Le format des motifs encode chaque champ explicitement.
Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

int triangle ( uint32_t phase)
static

Calculer une onde triangulaire à partir d'une phase DDS.

Les neuf bits de poids fort désignent 512 positions dans la période. Deux segments linéaires produisent le signal sans table ni fonction trigonométrique.

Paramètres
