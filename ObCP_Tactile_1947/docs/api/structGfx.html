Description détaillée

Vue de dessin sur un tampon de bande RGB565.

Le pas mémoire est clip.w. Changer seulement clip modifierait aussi ce pas. Les primitives réalisent donc leur propre intersection tout en conservant cette vue.

Définition à la ligne 64 du fichier obcp_gfx.h.
