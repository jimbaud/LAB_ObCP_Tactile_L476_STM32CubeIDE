Description détaillée

Neutre, filtre et commande d’inclinaison.

Le neutre et les mesures filtrées sont dans le repère brut du capteur. x et y sont dans le repère écran après permutation, signes, zone morte et gain.

Définition à la ligne 199 du fichier obcp_input.h.
