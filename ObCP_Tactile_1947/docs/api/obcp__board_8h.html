Description détaillée

Ordonnancement coopératif et liaison avec la carte réelle.

Ce module possède App, Renderer et les états d’entrée. Il cadence les tâches sans RTOS, arbitre l’affichage, prépare les demandes flash et expose obcp_live au débogueur. Les callbacks d’interruption se limitent à leurs pilotes.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

◆ obcp_flash_ecc_nmi()

bool obcp_flash_ecc_nmi ( void )

Reconnaître une NMI provoquée par une erreur ECC double.

Le bit ECCD est acquitté et un indicateur volatile mémorise l'erreur pour la lecture en cours. Les autres causes de NMI restent à traiter par le gestionnaire généré.

Renvoie
true si la cause ECCD a été prise en charge.
Note
Appel depuis NMI_Handler(). L’indicateur est consulté par la lecture flash.

Définition à la ligne 64 du fichier flash_port.c.

void obcp_task ( void )

Servir une itération de toutes les tâches de l'application.

Priorise l'audio, les entrées et au plus quatre pas de simulation de rattrapage. Sert le rendu puis un travail flash lorsque son message a pu être affiché. À appeler continuellement depuis USER CODE 3.
