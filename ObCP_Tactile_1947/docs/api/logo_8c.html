Description détaillée

Ressource graphique SUPMICROTECH compressée par lignes.

Le fichier est produit par Tools/import_logo.py depuis le JPEG CMJN fourni. La palette RGB565 et les couples longueur-indice sont en flash. Une table d’offsets permet de lire directement les seules lignes de la bande active.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

Documentation des fonctions

◆ logo_draw()

void logo_draw ( Gfx * g,
int x,
int y )

Décompresser les lignes visibles du logo dans une bande.

Pour chaque ligne utile, les couples longueur-indice décrivent des segments de couleur constante. Le rendu ne crée aucun tampon du logo et garde le pas de la bande Gfx.

Paramètres
[in,out]gVue de la bande RGB565 et de son tampon accessible en écriture. Pointeur valide.
[in]xAbscisse dans le repère écran, en pixels.
[in]yOrdonnée dans le repère écran, en pixels.
