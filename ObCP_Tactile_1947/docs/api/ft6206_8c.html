Description détaillée

Lecture du premier contact capacitif FT62xx sur I²C1.

Le capteur est sondé à l’adresse 7 bits 0x38. La HAL reçoit cette adresse décalée d’un bit. Ce pilote livre les coordonnées natives. Le passage en paysage est réalisé par input.c.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

◆ ft6206_probe()

bool ft6206_probe ( uint8_t * chip)

Vérifier l'identifiant de famille du tactile capacitif.

Le registre 0xA3 est lu. Les identifiants 0x06, 0x36 et 0x64 sont admis. Le résultat de sortie commence à zéro pour éviter une identité résiduelle.

Paramètres
[out]chipPointeur valide recevant l’identifiant lu du composant.
Renvoie
true si une signature compatible est reçue.

◆ ft6206_sample()

bool ft6206_sample ( bool * pressed,
uint16_t * raw_x,
uint16_t * raw_y )

Lire l'état et les coordonnées du premier doigt.

Une rafale contient TD_STATUS et les deux coordonnées sur 12 bits. L'événement natif de relâchement ne doit pas devenir un nouvel appui. Les coordonnées sont écrites seulement si le doigt est présent.

Paramètres
[out]pressedPointeur valide recevant true lorsqu’un doigt est présent.
[out]raw_xCoordonnée native de sortie, écrite seulement lorsque le contact est présent.
[out]raw_yCoordonnée native de sortie, écrite seulement lorsque le contact est présent.
Renvoie
true si la transaction réussit, y compris lorsque pressed vaut false.

Lire une plage de registres FT62xx.

Le pilote évite de démarrer si le bus est marqué occupé. La HAL utilise une adresse de registre sur huit bits et un délai limité à quatre millisecondes.

Paramètres

[out]dataTampon recevant au moins len octets consécutifs de registres.
[in]sizeLongueur du bloc en octets.
Renvoie
true si tous les registres sont reçus.
