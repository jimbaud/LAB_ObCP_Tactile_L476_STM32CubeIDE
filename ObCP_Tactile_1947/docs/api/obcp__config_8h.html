Description détaillée

Valeurs initiales de repère pour le montage ObCP.

Ces constantes définissent le paysage de départ. Les paramètres sauvegardés et l’assistant peuvent ensuite remplacer le repère des jeux en RAM.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

Définition dans le fichier obcp_config.h.
