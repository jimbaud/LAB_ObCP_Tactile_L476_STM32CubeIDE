Description détaillée

Reconnaissance des shields et façade tactile commune.

L’application lit toujours un RawTouch et un état TouchRead. La façade choisit un protocole capacitif I²C, résistif SPI ou résistif I²C. Un état WAIT conserve la possibilité de servir d’autres tâches entre deux étapes.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

Valeurs énumérées

◆ touch_probe()

bool touch_probe ( TouchDevice * device)

Reconnaître le contrôleur tactile présent.

Vérifie d'abord que SPI1 peut être utilisé, essaie les signatures FT62xx puis STMPE610, enfin le protocole TSC2007. Une recherche terminée peut produire TOUCH_CTRL_NONE.

Paramètres
[in,out]deviceType et identifiant du contrôleur tactile. Pointeur valide.
Renvoie
true si la recherche a pu être effectuée. false quand le SPI est occupé.
