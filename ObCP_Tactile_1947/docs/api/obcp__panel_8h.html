Description détaillée

Commandes du TFT ILI9341 et transport SPI1 DMA.

Le TFT utilise CS sur D10 et D/C sur D9. L’initialisation et les petites commandes sont synchrones. Les pixels sont transmis par DMA1 canal 3. Le STMPE610 peut emprunter SPI1 uniquement entre ces bandes.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

◆ lcd_init()

bool lcd_init ( uint16_t * id)

Initialiser le TFT en paysage RGB565.

Lit l'identifiant, applique la séquence d'alimentation et de gamma, choisit MADCTL et sort le contrôleur du sommeil. Cette étape unique peut utiliser les délais requis au démarrage.

Paramètres
[out]idPointeur valide recevant l’identifiant lu du composant.
Renvoie
true si les échanges d'initialisation ont réussi. L'identifiant est fourni séparément.

◆ lcd_spi_available()

bool lcd_spi_available ( void )

Vérifier si SPI1 peut servir le tactile résistif.

Le transport ne doit plus être BUSY, la HAL doit être prête et le bit matériel BSY doit être effacé.

Renvoie
true si le STMPE610 peut emprunter le bus.
