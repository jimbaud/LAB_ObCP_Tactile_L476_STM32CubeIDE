 Quatre cibles écran de référence. Les trois premières ajustent et la quatrième contrôle.

Description détaillée

Transformation affine et assistant de calibrage résistif.

Trois contacts bruts définissent une base. Une quatrième cible indépendante vérifie la transformation avant sauvegarde. Les deux profils, TSC2007 et STMPE610, sont stockés sous forme de points pour reconstruire les coefficients au chargement.

Repères de lecture
Les coordonnées écran sont en pixels. Les durées suffixées ms sont en millisecondes. Les adresses du service de stockage sont des offsets en octets.

bool touch_cal_fit ( TouchCalibration * cal,
const RawPoint points[CAL_FIT_COUNT] )

Calculer une transformation affine de trois points bruts.

Le déterminant de deux vecteurs permet d'inverser la base. Un déterminant trop petit rejette des observations alignées ou trop proches. Le candidat remplace cal seulement si le calcul est admis.

Paramètres
[in,out]calTransformation affine et observations de référence. Pointeur valide.
[in]pointsTrois observations brutes, dans l’ordre des cibles de référence.
Renvoie
true si une transformation exploitable est calculée.
